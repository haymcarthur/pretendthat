# Setup builds areas; every printout gets used in the scene (Haylee's idea, 2026-11-21, not built yet)

**Haylee:**
- Setup should build the play space by AREA: a spaceship = cockpit, engine area, passenger area; a restaurant = kitchen, dining area, host stand, entrance; a treasure hunt = hide the treasure, pick a starting point, put supplies in places. All using the props and printouts.
- The scene ignores many printouts (space action cards, the captain's log, a travel game's passport). Badges, signs, menus and money get used; others don't. Whatever we print should be used during play.

**Claude's take:**
- Areas: yes. Each area has an owner role (captain → cockpit), so ownership and fair jobs come naturally. Props and printouts are placed in an area, and events can point at areas ("the engine room is beeping!"). 2–4 areas, merged for 1–2 kids.
- Printouts: give every printable TYPE a "play job" (like the prop stand-ins): action cards = draw one in a calm stretch and act it out; captain's log = write or check off what happened; passport = get a stamp at each stop; tickets = hand over to board; map = used in a navigation event. Code check: every printout is used in the opener, an event or a calm-stretch idea (wearables like badges are covered by setup).
- Add short calm-stretch "ideas" between events (no chime; "While we fly, Captain, write in your log what you saw"), so quiet time has a nudge and the printouts get used.
- Cost: slightly bigger guide (~+0.5¢). Do it after the current round.
