# Problem and audience

- **Date:** 2026-11-13
- **Decided by:** Haylee

**Decision:** Build for kids ages 4–8 who play make-believe (airplane, store, hotel, vet). The pain points: setup (stand-in props, homemade tickets and money using materials parents don't want used) and "we're set up, now what?". Kids are non-readers, so everything uses pictures plus tap-to-hear audio. Parents do the printing.

**Why:** Haylee's own kids. Parents end up saying "not right now"; kids want independence.
