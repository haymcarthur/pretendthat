## 1. Badges and tickets: drawn once for 6, the first N print
- **Which printables are per-player:** only badges and tickets (`KitRecipe.perPlayer`). Every other type prints its own
  entries whatever the count: money, menus, cards, medals, stickers, labels, the passport (one fold-in booklet) and so on.
- **First play:** the badge page always shows all 6 ranked roles in rank order, read left to right and top to bottom. The
  ticket page always shows 6 passes, each with its own number (boarding 1A 1B 1C 1D 2A 2B, admission 001–006,
  rooms 101–106, appointments 1–6). Before this round there were 8 tickets a page. Each page uses a shared "strict
  grid" prompt block: exactly 6 equal pieces, even wide plain gutters, nothing in the gutters, every piece whole in its
  own cell, plus the existing dashed CUT block. Grids (Claude's call): tall lanyard tags are 3 × 2; round pins and wide
  ID cards are 2 × 3; tickets are 2 × 3.
- **Art keys:** `badges@all` and `tickets@all` are drawn once per set, whatever the count. A change of count never draws
  again, and that includes a count change during the first play (round 46 drew a new `badges@N` page for it).
- **Cutting (`SheetCells`, NutmegCore, pure pixel math):**
  - Ink becomes connected blobs on a half-size mask. The 6 biggest top-level blobs are the pieces. A blob sitting inside
    another blob's bounds counts as part of that blob, so a solid cut line around a badge still works.
  - The 6 pieces must be about the same size (within ±30%) and must not overlap. If a 7th blob is close to piece size,
    the check fails.
  - The other blobs join the pieces as the pieces grow outward together, one pixel step at a time. A ticket's separate
    stub frame joins its own ticket first, so the seat number inside the stub stays with that ticket.
  - Each crop is the piece's own blobs plus a little paper, and it never reaches into another piece. Any of a neighbor's
    dashes or sparkles inside the crop is painted white.
  - Any doubt returns nil and the WHOLE page prints instead (never the app-drawn look): pieces touching, 5 pieces for 6,
    a 7th piece-sized blob, or uneven sizes.
- **Printing (`AIPiecesPageView`, `SheetCells.layout`):**
  - The first N pieces go in the sheet's own reading order and columns. Each row is centered, starting at the top of
    the half-inch margin.
  - Each piece prints at the scale the whole page would print at, so a badge is the same size for any count. Pieces
    shrink evenly only if they wouldn't fit.
  - With 6 players the whole drawn page prints as is. Nothing is drawn on the art.
  - KitPrinter, the Print screen, the pinned card and the live harness all use one view, `KitArtService.pageView`.
- **Replays:** the pieces aren't saved. A replay cuts its saved `@all` sheet again (about 15 ms, no image call).
- **Saved-game compatibility:** no schema bump was needed (still 5; the keys are just strings).
  - A round 46 game has no `@all` key, so the page is found under its old key (`badges@N` for the count it was first
    played with, `tickets` for tickets) and prints whole, exactly as round 46 did.
  - A round 46 game replayed with a different count falls back to round 46's app-drawn badge page. Only new games get
    the "any count" behavior.
- **Image count:** unchanged from round 46. That is one page per printable per set, plus the character sheet and the
  cover: 14 images for a 6-printable kit. Count changes no longer add a badge page.

## 2. The outline word check (Haylee's choice b)
`OutlineWordCheck`: the color set always reads its pages. An outline (bubble-letter) page is read only when the same
printable's color page missed on its FIRST drawing. Read means the check, then one redraw on a real miss, as in round 46.
- **If the color page read fine:** the outline page is kept unread.
- **If the color page failed to draw:** the outline page is also kept unread.
- **If the color verdict isn't in yet:** the outline page waits for it, then decides (at most 3 minutes).

The color and outline sets share a `WordCheckBoard`, which holds page keys only. The log says "not read (the color page
read fine)".
