# Button audit decisions (Haylee, 2026-11-16)

Kids 4–8 mostly can't read, so we use as few buttons as possible, with voice first. Grown-up screens (the gate, the Grown-ups page, delete) keep text buttons.

1. **Pick confirm:** no buttons; voice only ("yes" or the fix), like the other talking steps.
2. **Color choice:** no buttons; voice only. **Changed mid-round 26 (Haylee): the color question is removed
   entirely;** coloring pages by default for now, both versions + the choice on the Print screen next round (see
   [round 26](2026-11-16-round26-buttons.md)).
3. **Hunt card:** icon-only big ✓ (found) and ✗ (don't have), no text.
4. **Print:** a printer-icon button plus a green ▶ play button. Remove the duplicate Print / Let's play behind the page preview.
5. **Hand-off card:** just a green ✓ check button (replaces "I'm the <Role>!"). Remove "Back to the checklist" on the hand-off card.
6. **Checklist:** no Done/✓ button; only the checklist. It moves on automatically when every step is checked (saying "we're done" still works).
7. **The End:** two icon buttons: ⭐ star = save the game and go home; 🏠 home = go home without saving. On a replay (already saved), only 🏠. Remove New game / Play it again / Save it. The rail's Play ↺ still goes back to the checklist.
8. **Replay Pick:** answer how many by voice; no number tiles, no Let's go.
9. **Replay Props:** works the same as the first time: one card at a time with ✓ / ✗.
10. **Replay Print:** the same as a first game: Print + ▶ Play (no "Just the badges").
11. **Start screen:** "New game" with a ▶ play icon, and "Saved games" with a ⭐ star icon (renames Let's play! / My games).

**Update (Haylee, 2026-11-16):** the color question is removed entirely. Kits will be generated in BOTH color and outline, the choice moves to the Print screen, and each game gets a colored, text-free cover image for the bookshelf. Queued as round 27.
