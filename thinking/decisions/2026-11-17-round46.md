## 1. The AI draws the whole page
- `KitPagePrompt` (NutmegCore/PagePrompts.swift) is the approved recipe in Swift: PAGE + the game (+ its place) + ONE style
  line per set (the same on every page of a kit) + the type's layout + WORDS (the only words, quoted exactly, with repeat
  counts) + CUT (sheets) + SAFE. A test checks the port word for word against 8 of the approved test pages (up to SAFE).
- All 17 types and every layout variant (now prompt variants): badges lanyard / round pin / ID card; sign door / banner /
  marquee; money bills / coins / tokens; tickets boarding / admission / keycard (an appointment card gets "Time: ___");
  menu card / board (kept light, no dark fill) / show program; cut-outs; order slips; map; clue cards; mission cards;
  log ruled / tick chart; medals; stickers and labels (each design twice); passport (fold-in-half); control panel.
  The code decoder stays app-drawn (its symbols must be exact). Color set + coloring set (bubble letters).
- Badges are drawn for exactly the playing roles; the page's art key is `badges@N`, so a count change draws that count's
  page only. Tickets: 8 a page, each with its own number written into the prompt (1A…2D, 001…008, Room 101…108; an
  appointment card 1…8). No skulls or crossbones anywhere (friendly pirates). Words come from the sanitizer's round 45
  limits (short), stray quotes are removed.
- The app draws NOTHING on the art: `KitPageView` fits the 2:3 page whole inside a half-inch margin (`PageFit`: 480 × 720
  pt on Letter, centered). A page whose art never comes prints round 45's app-drawn page instead (LibraryPages stays for
  that and for round 45 replays).
- Skipped props (Claude's call): the themed cut-outs page is drawn during the hunt as before; skipped props' cut-outs are a
  second page "More <title>" (`cutouts#more`, `KitItem.pageLines`), one image per set (round 45 drew one per prop).
- Same image model, quality, size fallbacks, limiter and relay path as before. The kit prompt tells Claude every word it
  writes is drawn exactly by a picture model.

## 2. One character sheet per kit (in-app pictures)
- The color set draws ONE picture-only sheet per kit: the 6 ranked roles' characters (waist up, dressed for the job) in the
  first two rows, then the kit's themed cut-out things (3 columns; 1024×1536, or 1536×1024 with no cut-outs). No words,
  frames or badges. It is sliced (any grid, short last row) into the scene rows' characters, the badge picture tiles and
  the cut-out (prop card) pictures; it saves and replays as `cut:characters:k`. Older games keep their own slices.
- Both live sheets sliced cleanly into 12 (see the contact sheets).

## 3. The forgiving word check
- Each page is read on the device (Apple Vision, accurate, language correction off; `PageOCR`) and checked with
  `PageWordCheck`: spaces, underscores, punctuation, case and accents don't count; Cyrillic/Greek look-alikes, 0/O,
  1/l/I and 5/S fold together; S before a digit = $; a phrase read in pieces counts; a repeated word needs half its
  copies; one-character words (a coin's "1", a card number) never force a redraw. On a real miss the page is redrawn
  ONCE (the missed words named again) and the better drawing is kept. Logged as page key + counts (no words in release).
- Tests: the test's 4 false misses with Vision's real readings, all 17 approved pages pass, real misses are caught.
