# Ensemble scenes replace hand-offs (Haylee, 2026-11-16)

- **No hand-offs and no checkboxes.** The iPad stays in the middle and all kids play each scene at the same time.
- **Each scene card has one row per playing role:** the role's character picture (cropped from the color badge: no badge frame, no blank name boxes), that role's ONE task for the scene, and a 🔊 button that reads just that task aloud.
- When a scene opens, Nutmeg sets it up ("Pretend that…") and reads everyone's task.
- **One big ▶ "Next scene" button.** There's no timer.
- **Tasks are bigger and interactive** (1–3 min each): they connect across roles in the same scene (Waiter takes the order while the Customer orders) and use only real props and kit items. They can imply talking but never script lines.
- **3 scenes per game** (about 15–25 min). A solo player gets the same 3 scenes with one row (tasks may be slightly bigger).
- Tasks are generated for all 6 ranked roles; only the playing roles show, so a count change needs no AI.
- **Supersedes:** round 28's per-role hand-off rotation, the queued "4 steps per role, everyone twice" structure, and the queued hand-off card art change (the character-crop idea moves into the scene rows).
