# Mascot: stage-manager mouse

- **Date:** 2026-11-13
- **Decided by:** Haylee

**Decision:** The mascot is a stage-manager mouse with a headset and clipboard (later named **Nutmeg**, she/her; see [mascot-nutmeg](mascot-nutmeg.md)). Talking style: the mouth opens and closes with voice volume (option A). Drawn in Figma as named layers and animated by code (idle, listening, thinking, talking, excited).

**Why:** The cardboard box ("Boxley") was rejected: it's too close to the boxley.app cardboard-robot mascot. The origami fox needs too many art variations for a solo builder. The mouse barely changes between games, and a "game master" mascot fits the positioning.
