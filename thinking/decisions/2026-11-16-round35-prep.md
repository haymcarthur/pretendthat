## 1. Onboarding plays through the game's speaker (Haylee's report: "her voice sounded different")
- Root cause (research/2026-11-16-onboarding-voice-investigation.md): onboarding had its own `AVAudioEngine` on a
  `.playback` / `.spokenAudio` session; the game uses `.playAndRecord` 48 kHz through `NutmegSpeaker`.
- **Fixed in the audio layer only** (onboarding views untouched; they get rebuilt next round). `OnboardingVoice` is now a
  thin wrapper: `ClipStore.bundledClip(for:)` → `speaker.startForClips()` → `speaker.playClip(...)`, the same path as
  replay clips (same engine, Varispeed 1.20 graph, re-link guards, lip sync). Its own engine is gone.
- **One session setup:** `NutmegAudioSession.nutmeg` (NutmegCore) = playAndRecord / default / [defaultToSpeaker,
  allowBluetoothA2DP] / 48 kHz preferred; `NutmegSpeaker.start` and the tap-fallback listener both call `apply()`.
- **No mic prompt before the Mic page (Claude's call, how):** `startForClips` starts the engine **output-only** until
  the mic is allowed (never touches `inputNode`; every `inputNode` use is behind `inputEnabled`). When the game connects,
  the session's `start` rebuilds the engine with the input (same session, same graph).
- **Measured (PT-R15, fresh install, mic permission reset):** screen 1 played the clip with
  `AUDIOFMT … PlayAndRecord/Default 48000 Hz (shared setup: true) … input off (output only)`, `VOICEFMT … heard ×1.200`,
  mic permission still **not asked** after playing, no prompt on screen. Tap-out of that clip: voiced span 5.664 s raw →
  4.736 s heard (**×1.196**), F0 258 → 314 Hz (**×1.215**). Hand-over test (onboarding clip output-only, then a live game):
  the game came up with input on, `heard ×1.200`.
- **Tests:** `allNutmegPlaybackGoesThroughTheSpeaker` (source scan: no AVSpeech, no other player node / pitch unit /
  `SpeakerGraph.wire`, no other engine except the input-only listener, nobody calls `setCategory`, no `.spokenAudio`;
  onboarding calls `speaker.playClip`; speaker uses `NutmegAudioSession.nutmeg.apply()`),
  `outputOnlyStartNeverTouchesTheInput`, `theOneSessionIsTheGamesSession`.
- **Needs the real iPad:** listen to onboarding screen 1 vs a New game greeting (should now match), and confirm no mic
  prompt before the Mic page on a fresh install (the simulator showed none).
