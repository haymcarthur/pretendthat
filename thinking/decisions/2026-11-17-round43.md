## 1. The audit fixes (F1–F6), in `PropFit` (no parallel system)
- **F1 head word:** `PropWords.head` takes the LAST word of the head phrase (before for/of/with…), and only that word.
  Possessives are never the head ("the pet's food" → food), hyphen words use their last part ("the check-in desk" → desk,
  "jet-pack" → pack). Plurals fold with `PrintedProps.singular`, which now keeps "-ie" words (cookies → cookie, not
  "cooky") and knows a few irregular ones (leaves, shelves, buses, glasses). `PrintedProps` uses the same parser.
  "Stuffed animal → the pet drying cloth" is now read as a CLOTH and rejected.
- **F2 vocabulary:** 44 rules with ~450 words (cloths, gloves, boots, goggles, keys, walls/towers, panels, stages,
  round things split into disc / ball / ring, tubes, drums, food, beds vs cushions, cups vs roomy holders, luggage…).
  Every curated use now has a known head word (tested). Abstract heads (hub, station, zone, sorter…) stay unknown.
- **F4 tags:** where it's worn (head, hand, feet, face, back, body), `fabric`, `disc`/`ball`/`ring`, `tube`, `rigid`,
  `floor` (the rug), `roomy` (holds several things: box, basket, bag… but not a cup). Paper and the rug lost `sheet`
  (never a cape or a tent); `surface` is a real raised top (table, stool, box, baking sheet), so a pillow is no counter and
  a tray no desk. Rides need a vehicle or big + sittable/boxy (no egg-carton rocket), shelters need big, helmets need a
  head thing that's a bowl shape, crowns a ring (headband) or a soft hat.
  Claude's calls from a shortlist read-through: an apron is no sail, a scarf no microphone, a wagon no bucket, a bag no
  drum, a bucket no bed, a pot no backpack.
- **Identity items** (Haylee: strict): stuffed animal → only a creature (pet, patient, baby, passenger, puppet); sneakers →
  shoes/boots; mittens, oven mitt → gloves or a hand puppet; sock → glove, puppet or a soft snowball; sunglasses → glasses,
  goggles, mask; toy car → rides; toy keys → keys; ball → round things (planet, snowball, sun, apple, pretend food);
  crayons → drawing tools or little wands; chalk → floor lines or drawing; flashlight → lights or a scope/scanner;
  umbrella (closed) → cane, wand, staff; jump rope → floor shapes only; hula hoop → floor shapes, a portal, a wheel.
  They reject unknown and abstract uses. **Flexible** items keep creative unknown uses (Haylee), logged in DEBUG as
  "PROP unknown use: bowl → the robot repair hub".
- **Parroted reasons:** a model reason that only repeats the pair ("A stuffed animal can be a pet drying cloth!",
  "It'll be the perfect treasure chest!") is replaced by the app's tag reason (`PropFit.parrots`).
- **The retry** names the problem: "Not shown: a stuffed animal can't become the pet drying cloth (a stuffed animal is only
  ever a creature: …). … e.g. towel, …, or keep the stuffed animal as what it really is: the patient, our pet."
- **F3 swap bug:** after the second misfit, `swap_prop` takes the first fitting unused item for the SAME use (the
  shortlist first, then the whole list); if nothing fits, the card becomes a pretend prop (its cut-out is printed),
  never "Pillow → the patient". The tap ✗ only swaps to an alternate that still fits and isn't used (`freshAlternate`).
- **Replay ✗:** the saved alternate is offered only if it still fits the card's use and isn't another card's item;
  otherwise the card goes straight to pretend.
- **F6 bundled game:** the airplane game's backpack is "Carry-on bag" (the kit still prints a Suitcase cut-out); its
  scene and setup lines say "carry-on bag". Tested with `PrintedProps.clash(kit:)` and `fits`.
  (Not changed, noted in the audit: the "guide failed" fallback still uses the airplane scenes for any game.)
- **Prompts:** the copied examples are gone ("a bakery: a bowl for the mixing bowl", "a vet clinic: a towel for the pet
  bed…", "Can you find a blanket/spoon/towel…", "I see a tray… snack cart", the show_next_prop "(bowl, pot, hat)" list and
  "A bowl is round like a captain's hat!"). Example lines use placeholders ("Can you find a <item>? It'll be <what it
  becomes>!"). New lines: the shortlist rule, "If the game has animals or patients, the stuffed animal is the animal or
  patient, never a thing for it", one sentence of the shape table (cloths and capes are fabric: towel, blanket, sheet,
  scarf, pillowcase), never the same item or use twice, and a reason that explains. Claude's props prompt has the same.
- **Library (Haylee):** the unplugged lamp is retired (59 items; an older saved game still shows its name and art,
  `PropLibrary.retired` / `hasArt`). The jump rope is a floor shape only. Everyday things come before toy-ish ones
  (doll bed, toy keys, toy broom, wagon, hula hoop, chalk) in every fallback, and a toy-ish FIRST prop gives way to an
  everyday alternate that fits the same use.

## 2. Hard no-repeat rule (Haylee)
Within one hunt never the same item twice and never the same pretend use twice. "Same use" = the same singular head noun
for a known use ("the treasure chest" = "a treasure chest" = "the gold chest"), else the same words without articles.
Enforced in code on every path: `show_next_prop` and `swap_prop` (one retry naming the problem, then the app's pair, which
skips used items and uses), the fallbacks (`sensibleFallback`, `PropFit.fallback`/`curatedPair` take `avoidingUses`),
Claude's tap-path list (`Validate.props` flags repeated uses for one re-ask, `PropFit.repair` fixes what's left), the tap ✗
and replays (above).

## 3. Variety: the per-game prop shortlist (Haylee: "box is always used")
- **`PropShortlist`** (NutmegCore/PropShortlist.swift), made at `set_roles` (voice) and before Claude's prop list (tap):
  8 picks + 4 backups, each with a use from this game's needs ("tray, e.g. the serving tray").
- **Needs** (`PropNeeds.uses`): 38 game profiles keyed by words (restaurant, bakery, vet/pet, doctor, zoo/farm, pirate,
  space, robots, airplane, train/bus, cars, castle/fairy, superheroes, camping, mail, shops, flowers, lemonade, ice cream,
  firefighters, salon, library, school, museum, dinosaurs, sea, tea party, detective, construction, circus/band/stage,
  hotel, weather, snow, bugs, rainbow, desert, toys, monsters), matched in the game type, title and theme first, then the
  role names and jobs. Things the game names itself come first ("Spaceship Laundromat" → the spaceship). Profiles are
  interleaved so a two-part game ("Bakery on the Moon") gets both. A made-up game that matches nothing gets generic uses.
- **Sampling:** items that fit one of the uses by a KNOWN rule; the 3 core uses each get an item first, then weighted
  sampling. Weight = 1 (+0.5 per extra use it fits, up to +1) × recency (last game ×0.15, then ×0.3, ×0.5, ×0.7, ×0.85)
  × 0.35 for the chronic box, bowl, blanket, pillow × 0.6 for toy-ish items. An item used in EACH of the last 2 games is
  excluded unless it's the only thing that can be a core use (the stuffed animal as a vet game's patient) or nothing else
  fits. Uses `RecentPropMemory.games` (library ids only, unchanged storage; nothing about kids).
- **Where the model sees it:** the set_roles result ("THIS GAME'S PROP SHORTLIST … choose EVERY prop from these list
  items, any other item is turned away: …; Backups for swap_prop …"), the show_next_prop / swap_prop descriptions, the
  instructions, Claude's props prompt, and the reconnect (resume) note. The tool enum stays the whole list (the cached
  prefix doesn't change per game).
- **Enforced:** an item off the shortlist (and its backups) gets one retry listing the shortlist, then a shortlist
  fallback (the first unused shortlist item that fits the model's use, else a shortlist pick with its own use). Card
  alternates are shortlist items. Round 30's "fresher" swap only runs when there's no shortlist (tests).
- `propShortlistOn` is set by the app (scripted store tests leave it off); `shortlistSeed` makes it repeatable; DEBUG logs
  "PROP shortlist: … · backups … · uses …".
- **Distribution (test, 50 simulated games over the 42 games × twists, the model taking the first 4–5 picks):** box in
  5 games, bowl 2, blanket 4, pillow 2; 52 different items used; the most used item other than the stuffed animal is in
  11 games (laundry basket). The stuffed animal is in 21: it's the one thing many games truly need (the patient, the
  dinosaur, the parrot, the penguins), as Haylee's identity rule intends. No item (besides that) was in 3 games in a row.
